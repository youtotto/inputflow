# InputFlow for kintone

InputFlow for kintoneは、入力ルール・明細ひな形・保存前入力チェックを無料で利用できるプラグインです。ルール一覧と自動入力の実行結果を確認でき、実際に値が変わった項目には入力中の印を表示します。

Releaseから `inputflow-for-kintone-1.0.0-free-bundle.zip` を取得して展開し、中の `inputflow-for-kintone-1.0.0-free-plugin.zip` をkintoneへ読み込んでください。PC版kintone向けです。詳しくは同梱の利用ガイドをご確認ください。

別アプリからの取り込みや別アプリへの登録・更新はInputFlow Proの機能です。製品紹介：https://www.nestrec.com/inputflow

無料版とPro版は同じプラグインIDを使います。入替えはドメイン内の利用アプリ全体へ反映されます。無料版へ入れ替えてもPro設定は保持されますが、Pro機能は実行されません。
